# q7m4v9x2k8 — Update Repository

This repository hosts only the **signed update artifacts** for the EVE Hauling Tracker desktop application:

- NSIS installer (.exe)
- updater signature (.sig)
- updater manifest (latest.json)

The application source code lives in a separate, private repository. No source code, secrets, keys, or user data is stored here.

To install the app, download the latest *-setup.exe from the [Releases](../../releases) page.
